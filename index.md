## KodeKloud 100 Days — Azure mastery (Days 1–50)

This site is a lightweight, browsable view of the repository content — weekly lab writeups, concise portfolio projects, and automation notes. Use the navigation at left to jump to a week or to the portfolio summaries.

### Quick links

- Portfolio — concise projects: `/portfolio/`
- Week notes — Week-1 .. Week-4: `/Week-1/week-1.md`, `/Week-2/week-2.md`, `/Week-3/week-3.md`, `/Week-4/week-4.md`

### How to preview locally

If you want to preview this repository as a static site (optional):

```bash
# install Ruby, Bundler, and Jekyll (if you don't have them)
bundle install || gem install bundler jekyll
bundle exec jekyll serve
# open http://localhost:4000
```

Notes
- I didn't alter any week content — this scaffold only adds a small site wrapper and navigation. Screenshots and attachments remain in their current locations.
